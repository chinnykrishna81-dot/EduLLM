# EDULLM MASTER PROMPT — COMPLETE TYPE 2 QUESTION BANK GENERATOR

## ROLE AND OBJECTIVE

Act as an expert CBSE/NCERT subject teacher, instructional designer, educational illustrator, question-bank architect, and frontend developer.

I will upload a PDF containing important questions, answers, explanations, and possibly diagrams for a particular chapter.

Your task is to transform the entire PDF into a **high-quality, interactive EduLLM Type 2 Question Bank**, suitable for students preparing for Class 10, 11, 12, and competitive examinations.

The final output must match the educational quality, visual presentation, and interaction style of our previously developed **EduLLM Chemical Reactions and Equations Type 2 Question Bank**.

**Important: Complete the entire chapter. Do not generate only sample questions or a partial demonstration.**

---

## 1. SOURCE PDF ANALYSIS — MANDATORY

Before generating content:

1. Read the entire uploaded PDF, including images, diagrams, tables, chemical equations, and handwritten content.
2. Identify the chapter name, topics, subtopics, and all numbered questions.
3. Count the exact number of questions in each section.
4. Preserve all source questions, including those with similar meanings.
5. Do not combine or delete questions merely because they belong to the same pattern.
6. Preserve the original scientific or mathematical meaning and intended answer.
7. Maintain source references such as page number and original question number.
8. Identify questions that require diagrams for understanding or solving.

Create a coverage index mapping every source question to its corresponding EduLLM question.

**Critical requirement:** If the source contains 62 questions, the final question bank must contain all 62 questions. Pattern grouping must never reduce the question count.

If source text is unclear or an answer appears incorrect, flag it for review. Do not silently invent or change source content.

---

## 2. CONVERT EVERY QUESTION INTO TYPE 2 FORMAT

Each original question becomes one main Type 2 question containing approximately 4–6 meaningful subquestions.

### Main Question

- Rephrase the original question using clear, student-friendly English.
- Preserve the original meaning, facts, conditions, and difficulty.
- Provide sufficient context without revealing the answer.
- For numerical questions, retain the necessary given values.
- For experiment-based questions, describe the setup and observations appropriately.

### Subquestions

Each subquestion must test a distinct learning objective.

Possible objectives include:

- Concept identification
- Understanding definitions
- Identifying observations
- Applying principles
- Interpreting equations
- Solving numerical problems
- Identifying reaction types
- Understanding cause and effect
- Logical reasoning
- Drawing conclusions

Avoid repetitive or meaningless subquestions.

**Bad example:**
"What is the answer to the main question?"

**Good example:**
"Why does the copper sulphate solution change colour when an iron nail is immersed in it?"

Subquestions must progressively develop the student's understanding of the main concept.

---

## 3. TWO ANSWER CHOICES FOR EVERY SUBQUESTION

Every subquestion must contain exactly two choices:

**A.** One possible answer

**B.** Another possible answer

Exactly one option must be correct.

Requirements:

- Both options should be scientifically or mathematically meaningful.
- The incorrect option should represent a plausible misconception.
- Avoid obviously absurd distractors.
- Randomize the position of the correct answer.
- Never reveal the correct answer through colour or styling before submission.
- Store the correct answer separately in JSON.
- Provide short feedback explaining why the correct option is right.
- Where helpful, explain why the incorrect option is wrong.

For numerical questions, provide realistic alternative results based on common calculation errors.

---

## 4. MARKS, DIFFICULTY, AND QUESTION CLASSIFICATION

Assign appropriate metadata to every question.

Required fields:

- Class
- Subject
- Chapter
- Topic
- Subtopic
- Question ID
- Original source question number
- Pattern ID
- Question type: Descriptive or Problem-solving
- Difficulty: Easy, Moderate, Hard
- Bloom's taxonomy level
- Total marks
- Individual subquestion marks
- Estimated solving time

Total marks must equal the sum of the marks assigned to subquestions.

---

## 5. PATTERN ID GROUPING

Identify questions that share the same underlying concept, reasoning method, or problem-solving technique.

Assign a consistent Pattern ID.

Examples:

- CHEM-COMBINATION-01
- CHEM-DECOMPOSITION-01
- CHEM-DISPLACEMENT-01
- CHEM-PRECIPITATION-01
- CHEM-REDOX-01
- MATH-AP-NTH-TERM-01
- MATH-AP-SUM-01

Similar questions may share a Pattern ID but must retain separate Question IDs and complete Type 2 content.

Generate a separate Pattern Index for EduLLM.

## 6. EDUCATIONAL IMAGES — EXTREMELY IMPORTANT

This is one of the most important requirements.

**Do not create generic flowcharts, empty rectangles, decorative boxes, or meaningless arrows and label them as educational illustrations.**

Use the source PDF's images and explanations as references.

For each question, determine whether a visual would genuinely help students understand the concept.

When an illustration is useful, create a **unique, colorful, scientifically accurate, hand-drawn textbook-style educational image**.

### Required illustration style

Use:

- Clean, colorful textbook illustrations
- Hand-drawn or hand-sketched educational artwork
- White or light pastel backgrounds
- Realistic but simplified laboratory apparatus
- Clearly distinguishable objects
- Proper scientific labels
- Correct chemical and mathematical notation
- Before / During / After illustrations where appropriate
- Correct observable colour changes
- Balanced chemical equations where relevant
- Short explanatory annotations
- Clear arrows showing processes
- Simple memory tips where useful

The illustration quality should resemble an excellent Class 10 NCERT supplementary study guide.

### Examples

For magnesium combustion, illustrate a magnesium ribbon, bright white flame, and white magnesium oxide powder.

For displacement reactions, show the actual metal strip or nail in a beaker, solution colour changes, and metal deposition.

For precipitation reactions, show the reactant solutions and the correctly coloured precipitate.

For rusting, show the iron object before and after corrosion.

For respiration, show a simple biological illustration explaining glucose oxidation and energy release.

For Mathematics, use appropriate graphs, geometric constructions, number lines, or visual problem-solving diagrams.

**Never reuse an unrelated illustration just to ensure every question has an image.**

If a question is better explained without an image, do not force one.

---

## 7. IMAGE PLACEMENT — STRICT RULE

The student must attempt the question before seeing the explanation.

Therefore:

**Default:** Place the hand-drawn illustration only in the explanation section, after answer submission.

**Exception:** If the original question explicitly requires interpreting a diagram, graph, apparatus, or figure, display the necessary question image before the subquestions.

Do not reveal the solution in a question image.

Maintain separate fields:

- `question_image_ref`
- `explanation_image_ref`

Each image must be saved as an individual file with a meaningful, stable filename.

Examples:

- Q001_Magnesium_Combustion.png
- Q012_Nitrogen_Food_Preservation.png
- Q018_Lead_Iodide_Precipitation.png

Ensure images are fully visible, not cropped, distorted, or overlapping.

## 9. EASY EXPLANATION FOR EVERY QUESTION

After the student submits answers, provide a complete, easy-to-understand explanation.

Use this structure:

**Easy Explanation**

Explain the concept in simple language suitable for the student's class.

**Step-by-Step Understanding**

Explain the relevant process, reaction, or calculation logically.

**Illustrated Explanation**

Display the question-specific hand-drawn diagram where appropriate.

**Important Points**

Provide approximately 3–5 concise takeaways.

**Remember**

Provide a short memory trick, formula, observation, or conceptual summary.

Explanations must teach the underlying concept, not merely repeat the correct option.

For problem-solving questions, show the complete working and explain why each step is performed.

## 10. INTERACTIVE HTML QUESTION BANK

Generate a complete, working HTML question bank.

Each question card must contain:

1. Main question
2. Topic and Pattern ID
3. Difficulty and marks
4. Relevant question image, only when necessary
5. Four to six meaningful subquestions
6. Two selectable answers per subquestion
7. Submit / Check Answers button
8. Correct and incorrect feedback
9. Total score
10. Easy explanation
11. Hand-drawn illustration in the explanation section
12. Key takeaways and memory tip

### Interaction rules

- Students select A or B.
- Answers remain hidden until submission.
- The interface calculates the score accurately.
- Feedback appears after submission.
- The explanation and its image appear after submission.
- Students can retry the question.
- Images load from separate asset files.

Add search and filters for topic, difficulty, question type, and Pattern ID.

Use responsive layouts suitable for desktop, tablet, and mobile.
